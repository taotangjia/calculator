# Java Calculator

A simple Java Calculator project built with Maven and tested with JUnit 5.
Created for the Software Development Tools course (Labs 3, 4, 5).

## Features
- Basic arithmetic: add, subtract, multiply, divide
- Helper operations: absolute value, maximum
- Unit tests with JUnit 5

## Build & Test Locally
```bash
mvn clean test
```

## CI/CD Status
This project uses **GitHub Actions** to automatically compile the source code
and run all JUnit tests on every push to `main` and on every pull request.
